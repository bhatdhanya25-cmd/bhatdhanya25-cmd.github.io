Blood Donation Management System

Overview

This project is a web-based application designed to manage blood donor records. It allows users to register donors, filter by city and blood group, and manage donor data efficiently.

Features

  • Donor registration with validation
  • Age restriction (18+)
  • Search by city
  • Filter by blood group
  • Dynamic donor list
  • Remove donor functionality

Technologies Used

  • HTML, CSS
  • AngularJS
  • PHP
  • XML
