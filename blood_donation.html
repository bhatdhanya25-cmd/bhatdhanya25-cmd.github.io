Blood Donation Management System

Overview

This project is a web-based application to manage blood donor records. Users can register donors, filter by city and blood group, and manage donor data.

Features

  • Donor registration
  • Age validation (18+)
  • Search by city
  • Filter by blood group
  • Dynamic donor list
  • Remove donor

Technologies Used

  • HTML, CSS
  • AngularJS
  • PHP (for backend)
  • XML
