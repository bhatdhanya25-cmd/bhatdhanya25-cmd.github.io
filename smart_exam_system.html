Smart Exam System

Backend-driven academic management system using PostgreSQL, SQL, Python, and FastAPI.

Project Overview

Smart Exam System is a backend-focused academic management system developed to manage students, teachers, departments, exams, and rankings efficiently. The project integrates PostgreSQL with FastAPI APIs to retrieve and manage real-time academic data.

Technologies Used

  • PostgreSQL
  • SQL
  • Python
  • FastAPI
  • psycopg2
  • Git & GitHub

Key Features

  • Student and Teacher Management
  • Department and Subject Tracking
  • Exam and Result Management
  • REST API Development using FastAPI
  • Topper Ranking System using SQL Window Functions
  • PostgreSQL Database Integration
  • Swagger API Documentation
  • JSON-based API Responses

Database Design

Designed a normalized relational database schema with primary keys, foreign keys, constraints, and entity relationships for efficient academic data management.

  • users
  • departments
  • students
  • teachers
  • subjects
  • exams
  • student_exam_attempts

SQL Concepts Implemented

Implemented advanced SQL concepts including JOIN queries, aggregate analysis, ranking queries, and SQL window functions.

  • JOIN Queries
  • Aggregate Functions
  • Ranking Queries
  • DENSE_RANK() Window Function
  • Views and Reporting Queries

REST API Endpoints

  • /students
  • /results
  • /topper

APIs dynamically retrieve and return PostgreSQL database data in structured JSON format.

Swagger API Documentation

FastAPI automatically generated interactive Swagger documentation for testing and validating REST APIs.

PostgreSQL Integration

Integrated PostgreSQL with FastAPI using psycopg2 to dynamically retrieve academic records and serve real-time API responses.

The system converts raw query outputs into professional JSON-formatted API responses for frontend and reporting integration.

Version Control & GitHub

Managed project version control using Git and GitHub including repository setup, commits, push workflows, and structured project organization.
